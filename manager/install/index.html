Put DCA Pro Manager on your phone

Install the operations console as an app: it opens from your home screen, runs full screen with no browser bars, and stays signed in between shifts. Nothing to download from an app store.

Install now

Your browser can add the app in one step.

iPhone & iPad

Open this page in Safari, then:

  1. Tap the Share button — the square with an arrow pointing up.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add. The DCA Manager icon appears on your home screen.

Add to Home Screen is only offered in Safari. If you are reading this in Chrome or another browser on iOS, open in Safari first.

Android

Open this page in Chrome, then:

  1. Tap Install app above, or the ⋮ menu in the top right.
  2. Choose Install app or Add to Home screen.
  3. Confirm Install. The app is added to your app drawer.

Samsung Internet and Firefox also work: look for Add page to or Install in the browser menu.
